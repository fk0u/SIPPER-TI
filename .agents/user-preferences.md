# User Preferences & Standards

## 1. UI & Navigation Philosophy
- **Separation of Concerns (Desktop vs Mobile):**
  - Tampilan navigasi desktop dan mobile wajib dibedakan secara sistematis dan ergonomis.
  - Desktop: Top Bar bersih dengan menu tautan penuh, badge status, profil popover, dan controls.
  - Mobile: Native mobile feel dengan header ringkas dan bottom tab navigation bar yang nyaman dijangkau satu tangan.
  - Larangan keras terhadap backdrop blur trap atau overlay yang mengunci layar mobile.
- **Production Standard:** Bangun sebagai "Real Apps" dengan arsitektur bersih, bukan sekadar prototype.
- **Iconography:** Mengutamakan icons modern dan tajam dari `lucide-react`.
- **Knowledge Management:** Selalu aktifkan ekosistem Graphify, dokumentasi arsitektur markdown yang lengkap, dan README komprehensif.
- **Language:** Gunakan Bahasa Indonesia dalam semua percakapan.
